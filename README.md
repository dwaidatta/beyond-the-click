# 🎮 Beyond the Click — Sunfruit Quest

A human verification checkbox reimagined as a **retro handheld console game**. No blurry text, no traffic lights, no "select all the crosswalks" — just a D-pad, two buttons, and a little pixel hero on a quest to prove you're human.

**[🌐 Try it live → dwaidatta.in/beyond-the-click](https://www.dwaidatta.in/beyond-the-click/)**

## ✨ What is this?

This is a **zero-dependency, fully synthesized** HTML/CSS/JavaScript challenge entry that turns boring CAPTCHA into a playable 80s Game Boy–style adventure.

💡 **The idea? 100% human.** A person got fed up with squinting at fire hydrants and traffic lights and thought: *"what if verifying you're human felt like fun instead of a chore?"*
🤖 **The code? 100% AI.** Every animation, hover effect, note of chiptune music, and line of game logic was generated by **Claude AI**, working through visual iteration and audio scheduling — human vision, machine execution.

- 🕹️ A working arcade game embedded in the verification flow
- 🎵 Original synthesized chiptune BGM that shifts intensity based on game state
- ✨ Playful tilts, glows, and shine effects on every element
- 📱 Fully responsive — works mobile, tablet, and desktop
- 🎨 Dark, vibrant aesthetic with zero external assets

## 🚀 Run it locally

No build step, no server, no `npm install` — pick your poison:

**Option A: Just open it** 🖱️

```bash
# Clone the repo
git clone <repo-url>
cd beyond-the-click

# Open in your browser
open index.html
# or just drag index.html into your browser
```

**Option B: VS Code + Live Server (recommended)** ⚡

1. Open the project folder in **VS Code**
2. Install the **Live Server** extension (by Ritwick Dey), if you haven't already
3. Right-click [index.html](index.html) → **"Open with Live Server"**
4. Your browser pops open with hot-reload — tweak the CSS and watch it update instantly ✨

That's it. Everything runs client-side, no matter which route you pick.

## 🎯 How to play

1. Click **"Verify you're human"** to open the handheld console
2. Use **arrow keys, WASD, or D-pad buttons** to move
3. Press **Space, A, B, or click the screen** to swing your sword
4. Defeat the monsters on three levels to complete the quest
5. Once verified, the checkbox auto-closes

### Sound

Press SELECT to toggle audio on/off (or use the music button top-right)
